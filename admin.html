Where should Save go?

💻 This computer's PORTFOLIO folder

Best while you work in VS Code. Save writes js/data.js and any uploaded images straight into your project folder. Then push with Git as usual. Works in Chrome or Edge.

🌐 GitHub (publish from anywhere, even your phone)

Save makes one commit to your repo, and GitHub Pages updates the live site in about a minute. You need a fine-grained token limited to your portfolio repo with Contents: Read and write. It stays in this browser only.

⬇️ Neither

Save downloads a new data.js (and any new images). Put them in js/ and assets/… yourself.
